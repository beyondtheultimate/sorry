# A Little Mission for You

A cute, pastel indie-style interactive mini-game built with vanilla HTML, CSS, and JavaScript.

## Features

- **Secret Access Gate** — Name verification screen with animated access granted and access denied responses.
- **Start Screen** — Playful mission introduction with animated clouds, twinkling stars, and floating hearts.
- **Level 1: Catch My Hearts** — Click or tap 5 gently drifting hearts to collect them all.
- **Level 2: A Little Quiz** — 3 lighthearted questions where every choice gives a playful reaction.
- **Final Chapter: The Letter** — Interactive 3D animated envelope revealing the secret letter, poem, and finale.

## Running Locally

Open `index.html` directly in any modern web browser, or serve the folder with any static file server.
